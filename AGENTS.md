Projet : EduGenius AI (Kids Edition), plateforme d'apprentissage pour enfants.
Je développe UNIQUEMENT le Module 2 : résumé de cours adapté à l'âge + flashcards.
Stack : backend FastAPI (Python 3.11), frontend Angular 18 (standalone components), MySQL.
Flux : le prof/parent upload un PDF, extraction du texte, l'IA génère un résumé
en style histoire adapté au niveau (8 ans / 12 ans), des flashcards et un glossaire
simple, le prof valide et publie, l'enfant lit et retourne les flashcards.
Règles : code simple, API REST JSON, clés dans .env, pas de sur-ingénierie,
commentaires courts. Ne modifie pas les fichiers des autres modules.
