# EduGenius AI (Kids Edition)

An intelligent, interactive learning platform designed for primary and middle school students.

## 🛠 Tech Stack
- **Backend:** Python 3.11+, FastAPI, Pydantic v2, SQLModel
- **Database:** MySQL 8.0
- **Frontend:** Angular 18+, TypeScript, SCSS
- **AI Integration:** Google Gemini API, Deep Learning Vision / Media

## 👥 Module Distribution
- **Module 1 (`features/auth` / `routers/auth.py`):** AI-Powered Smart Auth & Safety
- **Module 2 (`features/lessons` / `routers/content.py`):** Kid-Friendly Lesson Summarizer & Flashcards
- **Module 3 (`features/tutor` / `routers/tutor.py`):** Safe AI Tutor Buddy Chatbot
- **Module 4 (`features/quiz-playground` / `routers/assessment.py`):** Quiz Playground, Smart Feedback & Progress Analyzer
- **Module 5 (`features/visual-studio` / `routers/visuals.py`):** Visual Schema & Video Explanation Generator
